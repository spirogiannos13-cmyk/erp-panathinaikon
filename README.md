# Panathinaikon ERP

Modern restaurant and hospitality management system.

## Current preview
A responsive, Greek-language dashboard prototype with a minimal green visual identity inspired by Panathinaikos green and white.

## Local development setup

### Prerequisites
- .NET 8 SDK (the backend targets .NET 8).
- Docker Desktop with Docker Compose.
- SQL Server container started from the repository root.

### 1. Prepare local configuration

For an existing panathinaikon-sql container, run this once from the repository root:

~~~powershell
.\scripts\Initialize-LocalDevelopment.ps1
~~~

The script:
- Reuses the password from the ignored root .env file, or safely recovers it from the existing Docker container if the file is missing/empty.
- Creates backend\Panathinaikon.Api\appsettings.Development.json with the SQL connection string.
- Generates a cryptographically random JWT signing key.
- Keeps Bootstrap:Enabled set to false.
- Does not modify, recreate, or initialize the database.

If this is a fresh installation with no SQL Server container yet, first create and configure the local environment file, then start SQL Server:

~~~powershell
Copy-Item .env.example .env
notepad .env
docker compose up -d sqlserver
~~~

Set a strong MSSQL_SA_PASSWORD in .env, then run the initialization script above.

The script will not overwrite an existing appsettings.Development.json. To intentionally regenerate its JWT key and replace the local settings, run:

~~~powershell
.\scripts\Initialize-LocalDevelopment.ps1 -Force
~~~

Never share or commit .env or appsettings.Development.json.

### 2. Initialize the database (only for a fresh database)

Only run the schema script when creating a new, empty database. Do not rerun it against an existing database:

~~~powershell
docker exec -it panathinaikon-sql /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "YOUR_LOCAL_SA_PASSWORD" -C -Q "IF DB_ID('PanathinaikonDb') IS NULL CREATE DATABASE PanathinaikonDb"
docker exec -i panathinaikon-sql /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "YOUR_LOCAL_SA_PASSWORD" -C -d PanathinaikonDb < database/schema.sql
~~~

For an existing database, apply only migrations that have not yet been applied. Back up first.

### 3. Run the backend

From the backend project directory:

~~~powershell
cd backend\Panathinaikon.Api
dotnet run
~~~

The checked-in launch profile sets ASPNETCORE_ENVIRONMENT=Development, so .NET loads the ignored appsettings.Development.json file automatically. Swagger is available at http://localhost:5080/swagger and health at http://localhost:5080/api/health.

### 4. Frontend preview

The static prototype can be opened by serving the repository root, for example:

~~~powershell
python -m http.server 5500
~~~

Then visit http://localhost:5500.

## Security notes
- Never commit .env, appsettings.Development.json, passwords, database connection strings, or JWT signing keys.
- appsettings.json intentionally contains empty secret values; local development values are generated by the setup script.
- The bootstrap endpoint is disabled by default. Do not enable it on a populated database.
- The dashboard is currently a prototype. Verify backend and frontend integration separately.
