# Panathinaikon ERP

Modern restaurant and hospitality management system.

## Current preview

A responsive, Greek-language dashboard prototype with:
- Minimal Green visual identity inspired by Panathinaikos green and white.
- Overview cards for sales, orders, average receipt and table occupancy.
- Switchable operation boards for Tables, Take Away and Delivery.
- Light and Dark appearance modes.
- Responsive desktop, tablet and mobile layouts.

## Run locally

No build tools or package installation are required for this prototype. Open `index.html` in a modern browser.

## Project direction

The dashboard currently uses sample data only. Backend services, authentication, persistence, real-time updates and operational workflows will be introduced in subsequent steps after the existing repository architecture and requirements are agreed.
